# StepFund 网页前端 —— 如何打开界面

**版本**：0.6.0　**打包日期**：2026-11-11
**本包只含前端**，不含合约工程与 Hardhat 工具链。

---

## 一、最快的方式：双击启动

1. 解压整个压缩包到任意目录（路径不要带 `#`、`&` 等特殊字符）。
2. 确认已安装 **Node.js 22.13 或更高版本**：命令行执行 `node -v` 检查。
3. 双击 **`Start Development.cmd`**。

脚本会自动做三件事：检查 Node → 若缺 `node_modules` 则执行 `npm ci` → 启动开发服务器，
并在服务就绪后自动打开浏览器 `http://127.0.0.1:5173/`。

首次运行需要联网下载依赖（约 1.5 GB，视网络 3～10 分钟）。命令窗口会打印编译与启动日志，
**这个窗口不要关闭**，关闭即停止服务。

## 二、手动方式

```bash
npm ci          # 首次，或删除 node_modules 之后
npm run dev     # 启动开发服务器
```

然后浏览器打开 <http://127.0.0.1:5173/>。

停止服务：在命令行窗口按 `Ctrl + C`。

## 三、只想要静态预览

```bash
npm ci
npm run build:portable
```

产物在 `dist/` 目录，可直接用任意静态服务器托管，不依赖 Node 运行时。
适合只做界面演示、不连链的场景。

## 四、界面里能看什么

- **Explore / 项目列表**：浏览进行中的众筹项目与进度。
- **项目详情**：里程碑、预算、投票、证据提交与资金释放状态。
- **创建项目**：填写标题、简介、分类、募资截止时间、投票周期与各里程碑预算。
- **连接中心 / 高级设置**：钱包连接、网络切换、参数微调。

> 前端默认连接本地开发链（`127.0.0.1:8545`）。若界面数据为空或一直转圈，
> 说明本地链没起——到 1 号源码包里执行 `npm run chain` 与 `npm run deploy:local` 即可。

## 五、常见问题

| 现象 | 原因 | 处置 |
|---|---|---|
| 双击后窗口一闪而过 | Node 未安装或版本过低 | 装 Node 22.13+ 后重试 |
| `npm ci` 报网络错误 | 代理 / 镜像问题 | 配置 npm 镜像后重试，或改用 `npm install` |
| 端口 5173 被占用 | 已有其他 dev server | 关掉旧进程，或 `set PORT=5174` 后重启 |
| 页面白屏 | 依赖安装不完整 | 删 `node_modules` 后重新 `npm ci` |
| 数据为空、一直加载 | 本地链未启动 | 见 1 号包，先 `npm run chain` |
| `EACCES` / 权限错误 | 解压到了受保护目录 | 换到用户目录（如 `D:\StepFund`）再试 |
